    اطلب مزامنة فورية عبر GitHub

    للمزامنة الفورية: افتح GitHub Actions واضغط Run workflow ثم Run workflow. يتطلب تسجيل الدخول لحساب GitHub المصرّح له.

    إزاي بتشتغل؟

    • يتم فحص قائمة المشاريع الحديثة تلقائيًا كل 6 ساعات بواسطة GitHub Actions؛ وقد يتأخر التشغيل بسبب جدولة GitHub.
    • يكتشف المشاريع الجديدة بالرقم الفريد، ويحافظ على المشاريع والصور الموجودة بالفعل بلا تكرار.
    • يحاول جلب الصور والنصوص من مزود Scrappa باستخدام مفتاح مخزن سرّيًا في GitHub؛ الرصيد المجاني له حدود استخدام.
    • لو Behance أو مصدر البيانات منع جلب الصور الكاملة، يظهر المشروع بالقدر المتاح، وقد يلزم استخدام أداة جمع الصور الداخلية الموجودة بالفعل.

    اللوحة للعرض فقط ولا تحتوي على مفاتيح API أو بيانات دخول. المشاريع الخاصة أو المسودات لا تُكتشف تلقائيًا.
