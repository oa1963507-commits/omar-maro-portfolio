نجمع صور المشاريع الكاملة، مش الأغلفة بس.

الأداة دي بتشتغل من متصفحك داخل Behance، وبتحاول تقرأ كل صور الـ28 مشروع وتجهز ملف JSON واحد. مفيش خدمة مدفوعة، ومش محتاج تبعت كلمة سر أو ملفات حسابك.

  1. اضغط Ctrl + Shift + B في Chrome علشان تظهر شريط المفضلة.
  2. اسحب الزر الأبيض اللي تحت لشريط المفضلة (مش مجرد ضغطة).
  3. افتح حسابك على Behance واضغط علامة المفضلة اللي أضفتها.
  4. هتشوف لوحة متابعة جوّه Behance. في النهاية اضغط تنزيل JSON وارفع الملف هنا في المحادثة.

الأداة تقرأ فقط روابط الصور العامة وعناوين المشاريع من صفحات Behance في متصفحك، ومش بتعمل أي طلب إلى خدمة خاصة بنا. لو Behance منع تحميل صفحة معيّنة داخل الإطار، هيتسجل المشروع كغير متاح بدل ما نعتبر صورة الغلاف مشروع كامل. راجع ملف JSON قبل مشاركته، وهو لا ينبغي أن يحتوي كلمات مرور أو رموز جلسة.

بعد ما تبعت الملف، هدمج النتائج مع GitHub من غير تكرار، وهحتفظ بأي مشروع قديم لو نسخة الاستخراج الجديدة ناقصة.
